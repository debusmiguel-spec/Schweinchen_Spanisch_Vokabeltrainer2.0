SPANISCH VOKABELTRAINER V5 – HANDY/PWA

Empfehlung: Verwende ein eigenes GitHub-Repository, z. B. "spanisch-vokabeltrainer".

1. ZIP entpacken.
2. Diese Dateien in das Repository hochladen:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - icon.svg
3. GitHub Pages aktivieren: Settings -> Pages -> Deploy from a branch -> main -> /(root)
4. Warten, bis die Veröffentlichung erfolgreich ist.

Android:
- GitHub-Pages-Adresse in Chrome öffnen.
- Menü -> App installieren / Zum Startbildschirm hinzufügen.

iPhone:
- GitHub-Pages-Adresse in Safari öffnen.
- Teilen -> Zum Home-Bildschirm.

Die spanischen Vokabeldaten werden getrennt von der englischen App gespeichert.
